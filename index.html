วิธีสร้าง Firebase ฟรี

  1. เปิด console.firebase.google.com แล้ว login ด้วย Google
  2. คลิก Add project → ตั้งชื่ออะไรก็ได้ (เช่น huahin-expense) → กด Continue → ปิด Google Analytics ก็ได้ → Create
  3. เมื่อสร้างเสร็จ คลิกไอคอน </> (Web) เพื่อเพิ่ม Web app → ตั้ง nickname → Register
  4. คัดลอกเฉพาะส่วน const firebaseConfig = {...} เอามาวางในช่อง
  5. เมนูซ้าย Build → Realtime Database → Create Database → เลือก location asia-southeast1 → Start in test mode → Enable
  6. เสร็จแล้ว — กลับมา paste config ที่นี่ได้เลย
⚠️ Test mode ใช้ได้ 30 วัน หลังจากนั้นต้องแก้ rules เป็น ".read": true, ".write": true หรือใส่ Auth ครับ
